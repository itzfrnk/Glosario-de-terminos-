**Término técnico (Español e Inglés):** 

  Bloque de Control de Proceso / Process Control Block

- Según William Stallings (2018), define este bloque como: “El bloque de control de proceso es la estructura de datos clave mantenida por el sistema operativo que contiene toda la información necesaria para gestionar un proceso específico”. El PCB Funciona como la ficha de identidad completa que permite apagar y reanudar tareas de forma segura.
