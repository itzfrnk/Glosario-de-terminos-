**Término técnico (Español e Inglés):** 

Sistema Básico de Entrada y Salida / Basic Input/Output System

- Según William Stallings (2018), define que: “El BIOS (Sistema Básico de Entrada y Salida) es el código de firmware inicial almacenado en memoria no volátil que se ejecuta al encender la computadora para inicializar y probar el hardware del sistema antes de cargar el sistema operativo”. Proporciona las rutinas de bajo nivel esenciales para la comunicación inicial entre los componentes físicos y el cargador de arranque, preparando el entorno para que el núcleo tome el control.
