**Término técnico (Español e Inglés):** 

Cambio de Modo / Mode Switch

·       Según William Stallings (2018), define que “un cambio de modo entre el modo usuario y el modo kernel es requerido cuando una aplicación necesita ejecutar una instrucción privilegiada o solicitar un servicio del sistema”. Esto actúa como un puente seguro que es controlado por hardware para transicionar la ejecución hacia rutinas más seguras.
