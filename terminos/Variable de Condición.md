**Término técnico (Español e Inglés):** 

Variable de Condición / Condition Variable

- Según Andrew S. Tanenbaum y Herbert Bos (2015), definen este mecanismo indicando que: “Una variable de condición es una construcción de sincronización utilizada junto con un monitor para permitir que un proceso se bloquee hasta que se cumpla cierta condición lógica”. Esta variable evita la espera activa al permitir la señalización de eventos entre los hilos.

*   **Anexo C (Conexiones):** Se conecta con [[Monitor de Sincronización]], [[Semáforo Binario]] y [[Exclusión Mutua]]
  
  - **Referencia bibliográfica**
Tanenbaum, A. S., & Bos, H. (2015). _Sistemas operativos modernos_ (4.ª ed.). Pearson Educación. Cap. 2.
