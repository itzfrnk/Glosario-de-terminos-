**Término técnico (Español e Inglés):** 

Llamada al Sistema (Syscall) / System Call

- Según Abraham Silberschatz, Peter B. Galvin y Greg Gagne (2018), definen que: “Una llamada al sistema proporciona la interfaz entre un proceso en ejecución y el sistema operativo, permitiendo que las aplicaciones soliciten servicios del núcleo como operaciones de E/S, creación de procesos o gestión de memoria”. Cuando se ejecuta una llamada al sistema, el procesador cambia de modo usuario a modo núcleo  mediante una instrucción especial o interrupción por software.

*   **Anexo C (Conexiones):** Se conecta con [[Interrupción por Software (Trap)]], [[Modo Kernel]] y [[Espacio de Usuario]]
  
  
  - Referencia bibliográfica Silberschatz, A., Galvin, P. B., & Gagne, G. (2018). _Operating System Concepts_ (10th ed.). John Wiley & Sons. Cap. 2.
