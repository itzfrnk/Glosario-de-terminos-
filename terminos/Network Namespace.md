**Término técnico (Español e Inglés):**

 Network Namespace / Espacio de Nombres de Red

- Según Robert Love (2010), define que: “Un espacio de nombres de red (_network namespace_) virtualiza la pila de red del sistema operativo, proporcionando a cada grupo de procesos su propia vista independiente de las interfaces de red, las tablas de enrutamiento y las reglas de filtrado de paquetes (_iptables_)”. Esta abstracción del kernel permite que los contenedores posean sus propias direcciones IP y puertos aislados de la red anfitriona y de otros contenedores.

*   **Anexo C (Conexiones):** Se conecta con [[Linux Namespaces]] y [[Contenedor]]
  
  - Referencia bibliográfica Love, R. (2010). _Linux Kernel Development_ (3.ª ed.). Addison-Wesley Professional.
