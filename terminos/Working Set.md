**Término técnico (Español e Inglés):** 

Working Set / Conjunto de Trabajo

·       Según Denning, P. J. (1968), define que: “El conjunto de trabajo de un proceso es el conjunto de páginas a las que el proceso hace referencia actualmente, lo cual representa la localidad de memoria necesaria para evitar un número excesivo de fallos de página”. En pocas palabras sirve como una base teórica para controlar el hiperpaginado estimando el conjunto activo de páginas indispensables para una ejecución estable.

*   **Anexo C (Conexiones):** Se conecta con [[Hiperpaginado (Thrashing)]] y [[Memoria Virtual]]
