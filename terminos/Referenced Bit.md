**Término técnico (Español e Inglés):** 

Referenced Bit / Bit de Referencia (Access Bit)

- Según Andrew S. Tanenbaum y Herbert Bos (2015), explican este indicador al señalar que: “El bit de referencia se establece automáticamente por el hardware cada vez que se lee o se escribe en una página, sirviendo de apoyo para los algoritmos de reemplazo de páginas”. Este bit permite identificar cuáles páginas poseen actividad reciente para optimizar las decisiones de desalojo en memoria.
