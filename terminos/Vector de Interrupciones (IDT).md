**Término técnico (Español e Inglés):**

 Vector de Interrupciones / Interrupt Vector Table o IDT (Interrupt Descriptor Table)

- Según William Stallings (2018), señala que: “el vector de interrupciones es una tabla estructurada que contiene las direcciones de las rutinas de servicio que deben ejecutarse cuando se genera cada tipo de interrupción”. En pocas palabras permite a la CPU saltar directamente al manejador de eventos correspondiente en tiempo constante.
