**Término técnico (Español e Inglés):** 

User Namespace / Espacio de Nombres de Usuario

- Según Abraham Silberschatz, Peter B. Galvin y Greg Gagne (2018),  definen que: “Los espacios de nombres de usuario son una característica de aislamiento del núcleo Linux que permite separar los identificadores de usuario y grupo (`UID` y `GID`) de un proceso respecto al sistema anfitrión”. Esta abstracción otorga a un proceso privilegios de administrador, dentro de un contenedor o entorno aislado sin comprometer la seguridad del sistema host, facilitando la implementación de contenedores seguros y la contención estricta de privilegios.

*   **Anexo C (Conexiones):** Se conecta con [[Linux Namespaces]] y [[Contenedor]]
  
  - Referencia bibliográfica Silberschatz, A., Galvin, P. B., & Gagne, G. (2018). _Operating System Concepts_ (10th ed.). John Wiley & Sons.
