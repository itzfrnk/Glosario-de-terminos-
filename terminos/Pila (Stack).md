Pila / Stack

- Según Abraham Silberschatz, Peter B. Galvin y Greg Gagne (2018), describen este segmento señalando: “La pila del proceso contiene datos temporales, como parámetros de funciones, direcciones de retorno y variables locales creadas durante la ejecución”. LA pila trabaja dentro de una estructura LIFO para asi gestionar de forma ordenada las llamadas a subrutinas.
