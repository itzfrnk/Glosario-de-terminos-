**Término técnico (Español e Inglés):** 

Espacio de Usuario / User Space

·       Según William Stallings (2018), define este entorno señalando que: “el espacio de usuario es la memoria destinada a las aplicaciones y programas donde las restricciones de privilegios impiden el acceso directo a los recursos físicos del sistema”. Ayuda a proteger la estabilidad del sistema operativo al encerrar los errores de las aplicaciones dentro de límites seguros.
