**Término técnico (Español e Inglés):** 

VirtualBox

- Según Andrew S. Tanenbaum y Herbert Bos (2014), define que: “VirtualBox es un hipervisor de código abierto desarrollado para sistemas operativos de escritorio que permite crear y ejecutar múltiples máquinas virtuales simultáneamente sobre un sistema anfitrión”. Este software emula componentes de hardware completos como procesadores, controladores de almacenamiento, interfaces de red y unidades gráficas, permitiendo que sistemas operativos invitados se ejecuten de forma aislada e independiente sobre la misma infraestructura física.
