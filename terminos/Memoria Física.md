**Término técnico (Español e Inglés):** 

Memoria Física / Physical Memory

- Según William Stallings (2018), define este recurso como: “La memoria física o principal es el almacenamiento de acceso directo que contiene los datos y programas activos que la CPU puede direccionar directamente”. Esta memoria física ofrece el espacio de trabajo inmediato y de alta velocidad que es necesario para la ejecución del software.

*   **Anexo C (Conexiones):** Se conecta con [[Memoria Virtual]] y [[Paginación]]
