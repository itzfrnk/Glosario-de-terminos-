**Término técnico (Español e Inglés):** 

Máquina Extendida / Extended Machine

- Según Andrew S. Tanenbaum y Herbert Bos (2015), definen la visión del sistema operativo al señalar que: “Visto desde la perspectiva del software de aplicación, el sistema operativo oculta la complejidad del hardware y crea una máquina extendida o máquina virtual más fácil de programar”. Una maquina extendida simplifica la interacción entre el código y los componentes físicos subyacentes.
