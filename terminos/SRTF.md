**Término técnico (Español e Inglés):** 

SRTF / Shortest Remaining Time First

- Según Abraham Silberschatz, Peter B. Galvin y Greg Gagne (2018), describen este esquema indicando que: “L a versión expropiativa del algoritmo SJF se conoce como planificación por el tiempo restante más corto, en la cual el planificador expropia la CPU si un nuevo proceso llega con un tiempo de ejecución restante menor que el del proceso actual”. El SRTF permite optimizar de una mejor manera el tiempo de espera global al priorizar dinámicamente las tareas más breves.
