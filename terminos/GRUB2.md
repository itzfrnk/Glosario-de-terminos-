**Término técnico (Español e Inglés):** 

GRUB2 / GRand Unified Bootloader version 2

- Según Robert Love (2010), define que: “GRUB2 es el cargador de arranque estándar en la mayoría de las distribuciones modernas de Linux, responsable de inicializar el hardware básico, cargar la imagen del núcleo (_kernel_) y transferirle el control del sistema durante el proceso de encendido”. Esta versión mejorada ofrece soporte para arquitecturas de 64 bits, sistemas de archivos avanzados y archivos de configuración altamente flexibles mediante scripts dinámicos.

*   **Anexo C (Conexiones):** Se conecta con [[Bootloader]], [[UEFI]] y [[Linux Kernel]]
  
  - Referencia bibliográfica Love, R. (2010). _Linux Kernel Development_ (3.ª ed.). Addison-Wesley Professional.
