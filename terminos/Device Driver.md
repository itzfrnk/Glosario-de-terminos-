**Término técnico (Español e Inglés):** 

Device Driver / Controlador de Dispositivo

- Según Abraham Silberschatz, Peter B. Galvin y Greg Gagne (2018), definen que: “Un controlador de dispositivo es una interfaz de software especializada que proporciona una capa de abstracción entre el núcleo del sistema operativo y los componentes de hardware específicos, traduciendo solicitudes genéricas de E/S en comandos de bajo nivel comprensibles para el controlador físico”. Este componente modular permite que el sistema operativo interactúe de forma uniforme con una gran variedad de periféricos sin necesidad de alterar la arquitectura interna del núcleo.
