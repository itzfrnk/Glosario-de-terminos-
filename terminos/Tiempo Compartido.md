**Término técnico (Español e Inglés):** 


Tiempo Compartido / Time-Sharing

- Según William Stallings (2018), define este esquema como: “El tiempo compartido es una técnica en la cual el procesador atiende a múltiples usuarios interactivos alternando velozmente la ejecución entre ellos”. Basicamente es proporcionar a cada usuario la ilusión de poseer el equipo de forma exclusiva.

*   **Anexo C (Conexiones):** Se conecta con [[Multiprogramación]], [[Quántum de Tiempo]] y [[Round Robin]]
