**Término técnico (Español e Inglés):** 

Contexto de Seguridad / Security Context

- Según Andrew S. Tanenbaum y Herbert Bos (2015), definen que: “El contexto de seguridad es el conjunto de privilegios, identificadores de usuario y políticas de control de acceso asignados a un proceso o hilo en ejecución para determinar qué recursos del sistema puede manipular”. Actúa como una frontera de protección fundamental dentro del núcleo para garantizar el aislamiento entre usuarios y prevenir la ejecución de operaciones no autorizadas.
