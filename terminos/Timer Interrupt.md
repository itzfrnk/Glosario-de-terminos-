**Término técnico (Español e Inglés):** 

Timer Interrupt / Interrupción del Temporizador

 Según William Stallings (2018), explica este componente como: “La interrupción de reloj es emitida a intervalos regulares por el hardware para permitir que el sistema operativo recupere el control de la CPU y realice la planificación de procesos”. El timer interrupt garantiza que el sistema operativo impida el control del procesador.
