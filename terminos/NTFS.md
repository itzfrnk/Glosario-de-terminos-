**Término técnico (Español e Inglés):** 

Sistema de Archivos de Nueva Tecnología / New Technology File System

- Según Abraham Silberschatz, Peter B. Galvin y Greg Gagne (2018), definen que: “NTFS es un sistema de archivos avanzado con arquitectura de registro (_journaling_) diseñado para ofrecer alta confiabilidad, seguridad y soporte para particiones de gran tamaño en entornos corporativos”. Este sistema organiza la información mediante una tabla maestra de archivos (_MFT_) y proporciona características nativas de control de acceso por listas de permisos (_ACL_), cifrado transparente (_EFS_) y recuperación automática ante fallos del sistema.

*   **Anexo C (Conexiones):** Se conecta con [[Sistema de Archivos]] y [[Journaling]]
  
  - Referencia bibliográfica Silberschatz, A., Galvin, P. B., & Gagne, G. (2018). _Operating System Concepts_ (10th ed.). John Wiley & Sons. Cap. 11.
