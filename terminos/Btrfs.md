**Término técnico (Español e Inglés):** 

Btrfs / B-tree File System

- Según Robert Love (2010), define que: “Btrfs es un sistema de archivos avanzado para Linux basado en la técnica de copia en escritura (CoW), diseñado para soportar grandes volúmenes de datos, instantáneas eficientes y gestión integrada de múltiples dispositivos de almacenamiento”. El btrfs proporciona una alta tolerancia a fallos, integridad de datos mediante sumas de verificación y la capacidad de escalar dinámicamente volúmenes de almacenamiento mediante agrupamiento.
