**Término técnico (Español e Inglés):**

 libc / C Standard Library

- Según Robert Love (2010), en su libro _Linux Kernel Development_, se define que: “`libc` es la biblioteca de software fundamental que proporciona la interfaz de programación de aplicaciones (_API_) estándar en lenguaje C, sirviendo como el puente esencial entre las aplicaciones del espacio de usuario y las llamadas al sistema (_syscalls_) expuestas por el núcleo del sistema operativo”. Además de envolver las llamadas directas al kernel, `libc` implementa funciones de alto nivel para gestión de memoria, manipulación de cadenas de texto y control de E/S, abstrayendo los detalles del hardware para garantizar la portabilidad de las aplicaciones en el sistema operativo.

*   **Anexo C (Conexiones):** Se conecta con [[Syscall (Llamada al Sistema)]] y [[POSIX]]
  
  Referencia bibliográfica Love, R. (2010). _Linux Kernel Development_ (3.ª ed.). Addison-Wesley Professional.
