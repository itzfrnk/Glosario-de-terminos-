**Término técnico (Español e Inglés):** 

Ring 0 / Ring 0 (Kernel Mode)

- Según Andrew S. Tanenbaum y Herbert Bos (2015), describen que: “El Anillo 0 es el nivel de ejecución con mayor privilegió en la arquitectura x86, reservado para el núcleo del sistema operativo para acceder directamente al hardware”. El ring 0 Garantiza el control total de la infraestructura sin interferencias externas.
