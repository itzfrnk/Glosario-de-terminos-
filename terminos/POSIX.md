**Término técnico (Español e Inglés):** 

POSIX / Portable Operating System Interface

- Según W. Richard Stevens y Stephen A. Rago (2013), definen que: “POSIX es una familia de estándares desarrollados por la IEEE que definen una interfaz de programa de aplicación (API) para garantizar la portabilidad del software entre distintas variantes de UNIX”. El posix estandariza la programación de llamadas al sistema y utilidades en diversos entornos de cómputo.

*   **Anexo C (Conexiones):** Se conecta con [[Filosofía UNIX]] y [[libc]]
