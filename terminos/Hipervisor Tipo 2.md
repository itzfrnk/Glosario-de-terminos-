**Término técnico (Español e Inglés):** 

Hipervisor Tipo 2 / Type 2 Hypervisor (Hosted)

- Según Andrew S. Tanenbaum y Herbert Bos (2015), definen que: “Un hipervisor de tipo 2 o hospedado es una aplicación de software que se ejecuta sobre un sistema operativo anfitrión convencional, encargándose de emular y gestionar las máquinas virtuales invitadas”. A diferencia del tipo 1, este enfoque depende del sistema operativo base para la asignación y el control del hardware físico, lo que introduce una sobrecarga de rendimiento adicional, pero ofrece una gran flexibilidad y facilidad de uso para entornos de prueba.
