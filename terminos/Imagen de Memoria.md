**Término técnico (Español e Inglés):** 

Imagen de Memoria / Memory Image (Core Image)

- Según William Stallings (2018), señala que: “La imagen de memoria de un proceso incluye el código ejecutable, los datos, la pila y el bloque de control del proceso necesarios para su ejecución en la memoria principal”. La imagen de memoria constituye al reflejo estructurado que el sistema operativo carga en la RAM para dar vida a un programa.
