**Término técnico (Español e Inglés):** 

Registro de Estado / Status Register o Flags Register

- Según William Stallings (2018), define que: “Contiene información de condición generada por el procesador, indicando el resultado de las operaciones aritméticas y el estado del control del sistema”. Este registro  de estado refleja las banderas operativas necesarias para la toma de decisiones lógicas inmediatas.

*   **Anexo C (Conexiones):** Se conecta con [[Contador de Programa (PC)]] y [[Puntero de Pila (SP)]]
  
  
  - **Referencia bibliográfica**
