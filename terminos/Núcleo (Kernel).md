**Término técnico (Español e Inglés):** 

Núcleo / Core

- Según Andrew S. Tanenbaum y Herbert Bos (2015), definen el núcleo indicando que: “El núcleo es el componente central del sistema operativo que se ejecuta en modo privilegiado y proporciona la interfaz fundamental entre el hardware y el software del sistema”. El núcleo kernel concentra las funciones críticas de control necesarias para el funcionamiento de todo el sistema operativo.
