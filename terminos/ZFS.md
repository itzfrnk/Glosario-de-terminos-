**Término técnico (Español e Inglés):** 

ZFS / Zettabyte File System

- Según Abraham Silberschatz, Peter B. Galvin y Greg Gagne (2018), define que: “ZFS es un sistema de archivos combinado y un administrador de volúmenes lógicos de 128 bits diseñado originalmente por Sun Microsystems, que integra la gestión de múltiples discos bajo un único grupo de almacenamiento dinámico (_zpool_)”. Este sistema destaca por garantizar la integridad total de los datos mediante el uso de sumas de verificación en tiempo real, soporte nativo para instantáneas, clonación eficiente y autorreparación ante fallos de redundancia.
