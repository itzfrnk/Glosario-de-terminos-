**Término técnico (Español e Inglés):** 

Servidor X11 / X Window System Server

- Según Andrew S. Tanenbaum y Herbert Bos (2014), definen que: “El servidor X11 o servidor X es el componente central del Sistema de Ventanas X encargado de gestionar los dispositivos de hardware de visualización, la entrada de teclado y ratón, y de coordinar el dibujo de las ventanas para las aplicaciones cliente”. Este modelo arquitectónico cliente-servidor permite que las aplicaciones gráficas se ejecuten de manera local o remota a través de una red, separando la lógica de la aplicación de la interfaz de usuario.

*   **Anexo C (Conexiones):** Se conecta con [[Compositor Wayland]] y [[Subsistema Gráfico Linux]]
  
  - Referencia bibliográfica Tanenbaum, A. S., & Bos, H. (2014). _Modern Operating Systems_ (4th ed.). Pearson.
