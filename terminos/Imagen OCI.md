**Término técnico (Español e Inglés):** 

Imagen OCI / OCI Image

- Según Andrew S. Tanenbaum y Herbert Bos (2015), define que: “Una imagen OCI es un estándar abierto e independiente de proveedor para empaquetar software en contenedores, el cual incluye un sistema de archivos en capas (_layers_), un manifiesto JSON y una configuración que describe cómo debe ejecutarse el contenedor”. Este formato estandarizado por la Open Container Initiative garantiza la interoperabilidad total entre diferentes motores de ejecución y plataformas de orquestación en la nube, permitiendo que cualquier entorno compatible despliegue la misma aplicación de forma idéntica.

*   **Anexo C (Conexiones):** Se conecta con [[Contenedor]], [[Docker]] y [[Podman]]
    
- Referencia bibliográfica Tanenbaum, A. S., & Bos, H. (2015). _Sistemas operativos modernos_ (4.ª ed.). Pearson Educación. Cap. 7.
