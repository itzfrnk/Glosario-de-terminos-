**Término técnico (Español e Inglés):

 PID / Process ID

- Según Andrew S. Tanenbaum y Herbert Bos (2015), explican esta variable como: “A cada proceso se le asigna un número entero único denominado identificador de proceso (PID) cuando es creado por el sistema operativo”. El PID facilita el rastreo, la señalización y el control individual de tareas en el núcleo mediante un numero.
