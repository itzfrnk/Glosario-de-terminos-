**Término técnico (Español e Inglés):** 

MBR / Master Boot Record

- Según Abraham Silberschatz, Peter B. Galvin y Greg Gagne (2018),  definen que: “El _Master Boot Record_ (MBR) es el primer sector físico (_sector 0_) de un dispositivo de almacenamiento particionado que contiene la tabla de particiones del disco y un pequeño programa de código ejecutable conocido como el gestor de arranque primario ”. Cuando la computadora enciende y completa la autoprueba de encendido (_POST_), el BIOS lee el MBR hacia la memoria principal y transfiere el control a dicho código para localizar y cargar el sistema operativo activo.
