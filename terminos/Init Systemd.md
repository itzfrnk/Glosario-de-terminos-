**Término técnico (Español e Inglés):** 

Sistema de Inicialización Systemd / Init Systemd

- Según Robert Love (2010), define que: “Systemd es un sistema de inicialización y gestor de servicios para Linux diseñado para reemplazar al tradicional System V (_SysVinit_), actuando como el proceso raíz con PID 1 que arranca el espacio de usuario y administra los servicios del sistema”. A diferencia de los scripts secuenciales antiguos, Systemd utiliza un enfoque basado en sockets y dependencias paralelas para acelerar significativamente el arranque del sistema operativo, además de supervisar de forma activa los procesos y gestionar los registros centralizados.

*   **Anexo C (Conexiones):** Se conecta con [[Bootloader]] y [[Proceso Huérfano]]
  
  - Referencia bibliográfica Love, R. (2010). _Linux Kernel Development_ (3.ª ed.). Addison-Wesley Professional.
