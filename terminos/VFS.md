**Término técnico (Español e Inglés):** 

Sistema de Archivos Virtual / Virtual File System 

- Según Abraham Silberschatz, Peter B. Galvin y Greg Gagne (2018),definen que: “El Sistema de Archivos Virtual es una capa de abstracción orientada a objetos en el núcleo del sistema operativo que permite a las aplicaciones acceder a diferentes tipos de sistemas de archivos físicos mediante una interfaz de programación unificada”. Esta arquitectura estandariza las operaciones comunes ocultando las diferencias, de modo que el núcleo puede gestionar de manera transparente tanto sistemas locales.
