**Término técnico (Español e Inglés):** 

Modo Usuario / User Mode

- Según William Stallings (2018), define este modo como: “En el modo usuario, los programas de aplicación ejecutan con un conjunto limitado de privilegios y no pueden acceder directamente al hardware ni a las áreas de memoria del núcleo”. Este modo establece una barrera de aislamiento que previene interferencias accidentales o maliciosas entre las aplicaciones.
