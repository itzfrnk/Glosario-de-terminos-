**Término técnico (Español e Inglés):** 

Estado Ejecutando / Running State

- Según Abraham Silberschatz, Peter B. Galvin y Greg Gagne (2018), definen que: “Un proceso se encuentra en el estado listo cuando está preparado para ejecutarse y solo espera a que el sistema operativo le asigne un núcleo de la CPU”. Este estado permite al planificador mantener un conjunto ordenado de procesos candidatos para ocupar rápidamente la unidad de procesamiento en cuanto se libere el recurso actual.
